# 第一阶段：多协议 LLM 终端对话客户端 Spec

> MewCode 是唯一项目根；本阶段代码直接进入根目录 `src/mewcode_cli/`，本目录只保存阶段文档。

## 背景

MewCode 是一个从零构建的、Claude Code 风格的终端 AI Agent。第一阶段先打通
“用户 ↔ LLM”的最小闭环：不引入工具调用、权限、记忆等高级能力，只提供可恢复、
可连续使用的终端多轮对话。

## 目标

- 同时支持 Anthropic Messages 协议和 OpenAI Chat Completions 协议，包括兼容端点。
- 提供 provider 启动选择、异步流式输出、Markdown 定型渲染和单会话多轮上下文。
- 请求失败时恢复可用的终端提示符，会话可以继续。
- 真实 API 密钥不进入版本控制或界面输出。

## 功能需求

- **F1 配置加载：** 从项目根目录 `.mewcode/config.yaml` 读取非空 `providers` 列表。每项
  包含 `name`、`protocol`、`api_key`、`model`，以及可选的 `base_url`、`thinking`。
  缺文件、YAML 无效、字段类型错误或必要字段缺失时，显示可读错误并终止。
- **F2 Provider 选择：** 只有一个 provider 时直接进入对话；多个时显示可用方向键和
  Enter 操作的选择列表，选中后再进入对话。本次进程内不再切换。
- **F3 多协议适配：** Anthropic 与 OpenAI 适配器向会话层暴露相同的异步文本增量接口。
  `base_url` 非空时覆盖 SDK 默认地址，兼容端点仍采用所选协议的请求格式。
- **F4 请求上下文：** 每轮请求包含内置 system prompt、此前所有成功完成的 user/assistant
  消息，以及本轮输入。默认要求简体中文回答；Anthropic `thinking: true` 启用扩展思考。
- **F5 流式接收：** 正文文本增量到达后立即交给界面；Anthropic thinking 增量被识别并
  丢弃，不得混入正文。
- **F6 多轮历史：** 只在一轮成功完成后原子提交本轮 user/assistant 消息。失败轮次显示在
  界面中，但不写入后续模型历史，避免不完整的角色序列。退出后不保留历史。
- **F7 TUI 布局：** 对话界面包含猫咪 banner、应用名和版本、当前工作目录、就绪提示、
  可滚动对话区、带 `❯` 和 placeholder 的多行输入框、provider/model 状态栏。
- **F8 回复渲染：** 流式期间以纯文本显示；完成后把正文作为 Markdown 渲染，支持代码块、
  列表和强调。
- **F9 输入提交：** Enter 提交非空文本；Alt+Enter 插入换行。Windows 可直接用系统快捷键
  切换中英文输入法；等待或流式期间输入框禁用，对话区仍可滚动，结束后恢复输入。
- **F10 退出：** 空闲时输入 `/exit`，或任意时刻按 Ctrl+C，安全退出并恢复终端状态。
- **F11 错误恢复：** 鉴权、限流、网络、模型或兼容端点错误以醒目样式显示；不得输出
  API 密钥、Python traceback 或使应用退出。
- **F12 响应计时：** 从提交开始显示 `正在思考... (Ns)` 并逐秒更新；正文开始后继续计时；
  结束时在已完成回复旁保留总耗时。

## 非功能需求

- **N1 异步响应：** 网络流不得阻塞 Textual 事件循环；等待时界面可刷新、滚动和退出。
- **N2 跨协议一致：** 除协议能力差异外，两种 provider 的输入、流式、历史和错误体验一致。
- **N3 配置健壮：** 配置错误包含具体路径或 `providers[index].field` 定位。
- **N4 密钥安全：** `.mewcode/config.yaml` 被 Git 忽略；密钥不出现在界面和测试快照中。
- **N5 终端兼容：** Textual 负责全屏与恢复；Windows IME 驱动使用 Win32 Unicode 输入。
- **N6 可测试：** 配置、会话事务、协议流解析和核心 TUI 流程可用 fake provider 自动验证。

## 不做的事

- 工具调用、MCP、权限确认、长期记忆、会话持久化和上下文压缩。
- `/exit` 之外的 slash 命令，以及运行时 provider/model 切换。
- 展示 thinking、单轮取消快捷键、多模态、token/费用统计。
- MewCode 自动重试或退避；两家 SDK 的默认自动重试也关闭。
- 环境变量或 CLI 参数覆盖 YAML。
- 退出后把全屏 TUI 内容复制到终端原生 scrollback；只保证应用内可滚动。

## 验收标准

- **AC1（F1）：** 合法配置能启动；缺文件、坏 YAML、空 providers、缺字段或非法 protocol
  均给出具体可读错误并非零退出。
- **AC2（F2）：** 单 provider 直接进入对话；多 provider 可用方向键选择，状态栏显示所选项。
- **AC3（F3）：** Anthropic、OpenAI 及至少一种自定义 `base_url` 通过同一 TUI 正常流式。
- **AC4（F4/F6）：** 第二轮收到此前成功历史；失败轮次不污染下一轮历史。
- **AC5（F5/F8）：** 正文增量实时出现，thinking 不可见；完成后 Markdown 正确渲染。
- **AC6（F7/F9）：** 布局完整；Enter 提交，Alt+Enter 换行，中英文可直接切换和混合输入。
- **AC7（F10）：** `/exit` 与 Ctrl+C 都能退出，终端随后正常。
- **AC8（F11）：** provider 抛错后显示脱敏错误并恢复输入，可继续下一轮。
- **AC9（F12）：** 首个增量前可见递增计时，完成块保留总耗时。
- **AC10（N1/N5）：** 慢流期间计时持续刷新、对话区可滚动，窄屏无明显错位。
- **AC11（N4/N6）：** 自动测试、格式化和 lint 通过；跟踪文件中不存在真实密钥。
